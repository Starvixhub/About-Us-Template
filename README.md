# STARVIXDEV | Sina Rezaei

**STARVIXDEV** is a personal developer portfolio created by Sina Rezaei to showcase development projects, technical articles, technology skills, and professional certifications.

The website features a dark, futuristic design with blue lighting, a custom developer workspace background, and a responsive layout.

## Features

- **Personal Branding:** STARVIXDEV identity and Sina Rezaei's name.
- **Technology Slider:** 24 technology logos displayed in groups of 8.
- **Featured Articles:** A collection of 8 technical articles with direct links.
- **Certificates:** A dedicated section for professional certifications.
- **Project Categories:** Six categories to organize projects:
  - Gaming
  - UI/UX
  - App Development
  - Development
  - Cybersecurity
  - Networking
- **Responsive Design:** Layout adapted for desktop and mobile screens.
- **Dual Brand Identity:** Links to both STARVIXDEV and STARVIXHUB.
